# Sports Scheduler

A web application for managing sports sessions.

## Features

- User Signup/Login
- Admin Sport Creation
- Session Creation
- MongoDB Atlas Integration
- Node.js Backend
- HTML/CSS/JavaScript Frontend

## Technologies

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB Atlas

## Run Locally

Backend:

```bash
cd backend
npm install
node server.js
```

Frontend:

Open index.html using Live Server.
Live Demo:https://sports-scheduler-frontend.netlify.app/
```
